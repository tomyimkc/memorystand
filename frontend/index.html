What to look for

  • The restart is the closest word match.
  • It is still unconfirmed.
  • The verified scale-up wins and stays held for a person.
  • The response reports the model-call count.

Why this is safer

Storage and authority are separate. A memory may remain searchable without receiving permission to steer an autonomous action.

Honest limit

This deployment matches words, not meaning. The decision route can fall back to a fixed policy; trust promotion itself uses zero model calls.

The trust ladder

Keep the memory. Limit its authority.

How it works

One ledger. Three independent jobs.

The public demo uses the deployed API and CockroachDB Cloud. Detailed implementation notes stay available without crowding the judge path.

CR

CockroachDB ledger

Stores facts, sources, trust tiers, ranked retrieval receipts, and later decisions together. Time travel reconstructs what the agent knew.

CW

CloudWatch check

Promotion requires the external system of record to agree. A direction, amount, metric, or entity mismatch refuses the claim.

The trust ladder

unconfirmed

No outcome has been reported for this decision yet.

attested

An outcome was reported, but this deployment could not independently re-check it (no PagerDuty token; a human sign-off has no system of record to re-query).

verified

Re-queried against the external system of record (CloudWatch), which agreed.

disputed

The reported outcome was a rollback, a false positive, or the external system of record disagreed with the claim.

Verification is delayed by design: confirming an outcome moments after a decision often lands on unavailable because the "after" metric window is still in the future — that is expected behaviour, not a broken feature.
